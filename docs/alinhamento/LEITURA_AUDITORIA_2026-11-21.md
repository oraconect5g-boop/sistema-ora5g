## 4. As soluções propostas pelo Codex (`SOLUCOES_PARA_AVALIACAO.md`)

Nenhum trecho foi copiado. O que foi aproveitado da ideia de cada uma:

- **O número fora do padrão (1):** o leitor separa o número do Excel do que não é, sem converter na leitura; a diferença para o exemplo é que a célula fora do padrão vale pelas regras do texto que o sistema já tinha (as mesmas de uma célula de texto), em vez de uma terceira regra só para ela.
- **O controle comum do crédito (2):** a trava da linha nos dois caminhos, como proposto; em vez de só validar nas duas funções, o uso virou a situação da linha, com gatilhos, para valer em qualquer caminho. A tabela de alocações (rateio) fica para quando houver o caso.
- **A publicação sem autorreferência (3):** o registro depois da publicação, fora do commit do aplicativo, numa branch própria.
